# Still Trying

A personal portfolio for sharing small products, AI learning notes, and ideas
for future collaboration.

## My Playground

- **小猫电视台 / Cat TV** — a content experiment designed specifically for cats.
- **[小猫游戏机 / Cat Arcade](https://game.catv.space)** — an interactive fishing pond game for cats, with adjustable age and personality modes.
- **[站一下 / Stand for a moment](https://tiny.catv.space)** — a lightweight break reminder for people who spend long periods sitting at work.
- **[小猫文学输入器 / Cat Literature Editor](https://chat.catv.space)** — a chat-story editor for writing cat-style dialogue and exporting complete long images.

The portfolio itself is deployed through Vercel from the `main` branch.

## Development

Requires Node.js 22 and pnpm.

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Validation

```bash
pnpm test
```

The project uses the standard Next.js App Router build and can be deployed
directly through Vercel's Git integration.
